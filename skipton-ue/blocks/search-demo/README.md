# search-demo

Custom **search-demo** block. 

## Authoring (Document Authoring)

Model: `standalone`

Single block table.

- Row 1 (required): four cells, `label | placeholder | button label | helper text`. Empty cells fall back to defaults ("Find your next adventure", "Try "family-friendly hiking"", "Search"); the helper text is hidden when empty.
- Row 2 (optional): one cell per sample result, with a bold/heading title, a description paragraph, and a link. These are shown after the form is submitted (UI-only demo, no real search).

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
